# 强动词词库（Action Verbs）

bullet 必须用强动词开头。**杜绝**："负责"、"协助"、"参与"、"帮助"——这些动词等于没说。

## 中文强动词（按场景分类）

### 主导 / 推动类
主导、牵头、发起、推动、驱动、领导、统筹、组织、协调、敲定、拍板、定调

### 创造 / 从零做起
搭建、构建、设计、开发、打造、上线、创立、孵化、原创、重构、重塑、立项

### 优化 / 改进
优化、提升、改进、迭代、升级、精简、加速、降本、提效、重构、扩展、加固

### 解决 / 攻坚
解决、攻克、修复、排查、定位、清除、消除、根治、止血、稳定

### 数据 / 业绩
增长、提升、降低、削减、节省、突破、达成、超额、收获、转化、变现

### 管理 / 团队
管理、带队、培养、辅导、招聘、扩编、考核、晋升、传帮带、建立梯队

### 沟通 / 跨部门
对接、协调、沟通、说服、谈判、达成共识、推动落地、跨部门协作、争取资源

### 学习 / 输出
研究、调研、复盘、沉淀、总结、输出、分享、培训、布道、撰写

## 弱动词黑名单（绝对不要用这些开头）

| 中文弱动词 | 改成 |
|---|---|
| 负责 | 主导 / 牵头 / 管理 |
| 协助 | 直接说你做了什么；如果只是协助而非主力，这条 bullet 大概率不该写 |
| 参与 | 同上 |
| 做 / 做了 | 设计 / 搭建 / 实现 |
| 帮助 | 主导 / 推动 / 加速 |
| 配合 | 协调 / 对接 / 推动 |
| 完成 | 达成 / 突破 / 超额完成 |
| 进行 | 用具体动词替换（"进行优化"→"优化"） |

| English Weak Verb | Replace With |
|---|---|
| Responsible for | Led / Owned / Managed |
| Assisted | Directly state action; if you only assisted, this bullet probably shouldn't exist |
| Helped | Drove / Accelerated / Enabled (with measurable outcome) |
| Worked on | Built / Delivered / Shipped |
| Participated in | Contributed by [specific action] |
| Did / Doing | Use the actual verb |
| Handled | Managed / Resolved / Owned |

## 一个判断标准

把动词去掉，只看后面的内容——能不能猜出你**具体做了什么**？

- ❌ "负责数据分析工作" → 去掉"负责"剩下"数据分析工作"，毫无信息
- ✅ "**搭建** Python 自动化报表系统" → 去掉"搭建"剩下系统名字，能猜出是从零做出来的
